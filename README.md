# LabTest Solutions S.L.

¡Bienvenido a LabTest Solutions!

Este repositorio contiene el sitio web de LabTest Solutions S.L., una empresa dedicada a realizar análisis, ensayos, y pruebas de laboratorio, así como controles de calidad.

## Nuestros servicios

- Análisis químicos.
- Análisis microbiológicos.
- Control de calidad de producto.
- Ensayos y pruebas de laboratorio.
- Elaboración de informes técnicos.

## Tecnologías utilizadas

- HTML5
- CSS3

## Cómo abrir la página web

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Haz doble clic sobre el archivo index.html.
4. La página web de abrirá en tu navegador.
